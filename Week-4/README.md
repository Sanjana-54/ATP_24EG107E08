# HTML & CSS Basics

This repository contains my Week 4 projects focused on learning and practicing the fundamentals of HTML and CSS. The exercises demonstrate a progressive understanding of webpage structure, elements, and basic styling.

## Projects Overview

### 1. `webpage_1.html`
A basic introduction to HTML structures. 
**Key concepts covered:**
- Document structure (`<html>`, `<head>`, `<body>`)
- Headings (`<h1>`) and Paragraphs (`<p>`)
- Hyperlinks (`<a>`) to external sites (e.g., Google)
- Unordered Lists (`<ul>`, `<li>`)
- HTML comments

### 2. `webpage_2.html`
An exercise focused on list organization and nesting.
**Key concepts covered:**
- Creating complex nested unordered lists (e.g., categorizing Fruits, Vegetables, etc.)
- Structuring hierarchical data in HTML

### 3. `webpage_3.html`
A slightly more complex webpage representing a simple profile for "Pochi the Cat", incorporating styling.
**Key concepts covered:**
- Linking an external CSS stylesheet (`styles.css`)
- Inserting and formatting images (`<img>`)
- Using subheadings (`<h2>`, `<h4>`)
- Ordered Lists (`<ol>`) for structured information
- Horizontal rules (`<hr>`) for visual separation

### 4. `styles.css`
An external stylesheet linked to `webpage_3.html` to provide basic visual styling and formatting to the HTML elements.

## How to Run
Simply clone this repository and open any of the `.html` files in your preferred web browser to view the pages..
