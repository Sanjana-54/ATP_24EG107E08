# Blog Application Frontend

This is the frontend of the Blog Application developed using React, Vite, Zustand, React Router, and Tailwind CSS.

## Features

- User Authentication
- Role-based Login (User, Author, Admin)
- Create and Manage Blogs
- Forgot Password Functionality
- Protected Routes
- Responsive UI
- Toast Notifications
- Profile Management

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- Axios
- Zustand
- React Router
- React Hook Form
- React Hot Toast

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Move to frontend folder:

```bash
cd Blog-frontend
```

Install dependencies:

```bash
npm install
```

Run the application:

```bash
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

## Folder Structure

- `components/` → Reusable UI components
- `pages/` → Application pages
- `Store/` → Zustand state management
- `styles/` → Common styles
- `assets/` → Images and static files

## Environment Variables

Create `.env` file if needed.

Example:

```env
VITE_API_URL=http://localhost:5000
```
