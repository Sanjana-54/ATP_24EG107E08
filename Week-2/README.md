# Week 2: JavaScript Core Concepts & Exercises

This directory contains coding exercises and projects completed during Week 2, focusing on core JavaScript features, array manipulation, ES6 features, and introductory backend concepts.

## 📂 Project Structure

- **[Array_operations](./Array_operations)**: Basic operations and methods for arrays in JavaScript.
- **[Array_operations_advanced](./Array_operations_advanced)**: Advanced array methods like `map`, `filter`, and `reduce`.
- **[Backend_1](./Backend_1)**: Introduction to basic backend concepts and setup.
- **[LibraryManagementSystem.js](./LibraryManagementSystem.js)**: A class-based JavaScript program to manage a library system, including adding books, borrowing, returning, and tracking availability using ES6 classes.
- **[Modules](./Modules)**: Examples demonstrating JavaScript ES6 Modules (`import` and `export` statements).
- **[Shallow&Deep](./Shallow&Deep)**: Understanding the critical differences between shallow copies and deep copies of objects and arrays in JavaScript.
- **[Spread_Rest](./Spread_Rest)**: Exercises and examples on using the Spread syntax (`...`) and Rest parameters for arrays and objects.
- **[Timer Functions](./Timer%20Functions)**: Working with asynchronous timer functions like `setTimeout` and `setInterval`.

## 🚀 Key Learnings & Highlights

- **Object-Oriented Programming (OOP)**: Modeled a complete system (Library Management) using ES6 classes and objects.
- **Modern ES6 Features**: Explored Spread/Rest operators and JS modules for cleaner, more maintainable code architecture.
- **Data Structures & Manipulation**: Deep dive into array methods and the nuances of copying data structures (Shallow vs. Deep copying).
- **Asynchronous Execution**: Controlled code execution timing using timer functions.
