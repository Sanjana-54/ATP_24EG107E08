# JavaScript Core Concepts & Exercises

This directory contains coding exercises focusing on core JavaScript features, array manipulation, modules, and asynchronous programming.

## 📂 Project Structure

- **[Array_operations](./Array_operations)**: Basic operations and methods for arrays in JavaScript.
- **[Array_operations_advanced](./Array_operations_advanced)**: Advanced array methods like `map`, `filter`, and `reduce`.
- **[Backend_1](./Backend_1)**: Introduction to basic backend concepts and setup.
- **[LibraryManagementSystem.js](./LibraryManagementSystem.js)**: A class-based JavaScript program to manage a library system, including adding books, borrowing, returning, and tracking availability using classes and objects.
- **[Modules](./Modules)**: Examples demonstrating JavaScript Modules using `import` and `export` statements.
- **[Shallow&Deep](./Shallow&Deep)**: Understanding the differences between shallow copies and deep copies in JavaScript.
- **[Spread_Rest](./Spread_Rest)**: Exercises and examples using Spread syntax (`...`) and Rest parameters.
- **[Timer Functions](./Timer%20Functions)**: Working with asynchronous functions like `setTimeout` and `setInterval`.

##  Key Learnings & Highlights

- **Object-Oriented Programming (OOP)**: Built a Library Management System using classes and objects.
- **Modern JavaScript Features**: Practiced modules, spread/rest operators, and clean code structure.
- **Array Manipulation**: Worked with powerful array methods like `map`, `filter`, and `reduce`.
- **Shallow vs Deep Copy**: Learned how data is copied and managed in JavaScript objects and arrays.
- **Asynchronous JavaScript**: Explored timer functions and delayed code execution using `setTimeout` and `setInterval`.
